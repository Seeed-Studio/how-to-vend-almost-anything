# Community records

Approved records live here after review. A GitHub issue is a proposal, not a listing.

The public site still reads its own JSON under `docs/en/data/` and `docs/ch/data/`. Those files stay empty until a person checks a submission. This folder is the place those approved records are kept.

| Folder | What belongs here |
| --- | --- |
| [`labs/`](labs/) | Approved lab participation. A FabLabs.io directory listing is not participation. |
| [`machines/`](machines/) | A deployment only after someone has checked it. |
| [`updates/`](updates/) | Announcements with review status approved. |
| [`individual/`](individual/) | An approved person record. Same review bar as a lab. Not a lab. |
