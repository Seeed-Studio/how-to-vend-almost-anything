02 / 增加一个替换件

一个新零件。
一条新记录。

不要改 V0 基线。把新的 CAD 文件加进仓库，再往 replacements.js 追加一个对象。页面会自动把最后一次修订标为当前，并保留上一个模型以便比较。

{
  partId: "dispenser",
  version: "V0.1",
  title: "宽体出货机构",
  source: "replacements/v0.1/wide-dispenser.stl",
  format: "stl",
  date: "2026-10-20",
  note: "改了什么，以及为什么。"
}
03 / 三维显示标准

让模型像一件产品，
而不是一个 CAD 视口。

页面应保住工程上的真实，同时用一套一致的视觉语言呈现机器。这些规则适用于 V0 以及之后的每一次替换。

01

相机

以略微抬高的四分之三视角打开。让机器第一眼就能看懂。不要永久自动旋转；运动只跟随使用者的意图。

02

材质

使用哑光、低金属度的 CAD 材质。系统颜色用来区分分组，颜色不是装饰。除非真实表面本身重要，否则避免照片级贴图。

03

焦点

选中或当前零件变为青柠色。未选中的几何体退到后面。选中内部零件时，外壳可以变虚，而不是消失。

04

爆炸

零件沿稳定的系统方向移动，并保持空间关系。默认是便于阅读的编辑式爆炸，0% 始终回到收拢状态。

05

标签

显示稳定的零件编号、名称、分组、数量和修订。标签尽量放在几何体之外，绝不用一段文字挡住物体。

06

运动

焦点、筛选和替换变化使用短促的缓出过渡。尊重减少动态的设置，并且不能必须靠动画才能看懂状态。

当前实心 + 青柠色焦点
V0 基线中性的工程材质
先前虚化 / 更低不透明度
提议轮廓或虚线，不能被看成已发布
开放的产品 / 持续修订

人能看懂的机器，才是人能改进的机器。
