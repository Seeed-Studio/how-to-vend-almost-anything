几个实际问题

我的实验室可以售卖什么？+

XIAO 是默认起点。你也可以添加适配的电子元件、学习套件和实验室制作的产品。产品尺寸和出货兼容性将影响机器设计。

哪些内容需要开源？+

机器以开源为基础。请将可复用的设计、机器改进、源文件和制造笔记分享给社区。第一版的参与规则与许可条款将在发布时公布。

我的实验室现在可以申请吗？+

实验室申请将在第一版发布后开放。现在可以参与设计，或在 GitHub 登记实验室的意向。意向登记不等于申请或名额分配。

Seeed Studio 如何参与？+

Seeed Studio 支持这一愿景，并提供开源参考作为起点。目标是支持共同设计及后续实验室推广。供货安排、申请资格和支持条款将在申请开放前公布。
