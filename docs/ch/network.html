网络

找到实验室。看看它在做什么。

查看世界各地的 Fab Lab，发现参与中的售货机，并在实验室真正公布之后，找到本地能拿到的 XIAO 板和创客产品。地图从 FabLabs.io 名录开始。那里的一个点不是售货机，也不是 Fab Foundation 的背书。

实验室列表

    来访者能找到什么

    一条目录不是库存数量。

    对已审核的实验室，产品可以出现在下面的类别里。“已列出的产品”只表示实验室写了它的名字。“最近确认可获得”需要一个日期。本站不编造实时库存或价格。

    Seeed Studio XIAO

    提议中的默认类别。本站没有确认任何库存。

    电子与元件

    实验室选择备着的板卡、传感器和零件。

    本地制作的物品

    实验室自己做的东西。它们不必开源。

    教育套件

    为课程或开放之夜准备的套装。

    工具与配件

    和电子产品放在一起的小工具。

    其他支持的产品

    已审核的机器被设置来放出的其他东西。

    安装

    新的机器。新的创客。新的地方。

    这里只出现已提交并获批准的安装。

    社群动态

    带审核状态的公开信息流。

    安装、升级、新产品、可获得性变化、开源修改和运营笔记。每一条公开内容都需要来源、时间和已通过的审核。一份提议不是一条目录。

    登记或更新你的实验室

    先经审核，再通过 GitHub issue 公开。

    GitHub Pages 自己不能保存表单。这些链接打开仓库里的 issue 表单。维护者审核 issue，然后编辑 JSON。以后的后端可以替换这个队列，而不必改这页的数据文件。

    登记兴趣

    告诉我们实验室想关注这个项目。这不会安装一台机器。

     提交已确认的安装

    机器版本、照片，以及审核者可以核对的来源。

     添加或更新产品目录

    名称和类别。一条目录不是声称它有库存。

     更新产品可获得性

    在显示为最近确认之前，必须有一个日期。

     公布机器升级

    改了什么，以及现在安装的是哪个版本。

     提交开源改进

    零件编号、CAD、版本、兼容性、测试证据、署名和许可。

     更正已有目录

    指出哪条记录是错的，以及更正的证据。

    世界地图如何填上

    每日快照，不是浏览器里的实时登录。

    api.fablabs.io 上旧的公开接口已经移除。当前开发者指南要求有人注册一个应用并完成一次 OAuth。本页只读取 directory-labs.json。令牌存为 secret 之后，GitHub Action 可以刷新这个文件。人必须做的事和 Action 能做的事写在 FABLABS_DIRECTORY.md。
