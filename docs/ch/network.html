参与共创探索实验室社区动态

由你的实验室，赋予本地特色。

共同的基础让每个实验室都能发挥自己的特色，每次改进又成为所有人的新起点。

  • 从 XIAO 开始。

    熟悉的开发板系列让创意有一个容易获得的起点。每个实验室自行确认产品供应情况。

  • 售卖社区需要的东西。

    选择元件、学习套件和自己的作品。产品尺寸与兼容的出货机构，决定机器能容纳什么。

  • 分享让它变好的方法。

    公开可复用的机器设计、改进、源文件和经验。明确版本与兼容性，让其他实验室接着你的工作前进。
