Open Fab Lab vending network

A vending machine in every Fab Lab.

Start with XIAO. Make it your own. Share what you build.

The aim is a machine any Fab Lab can construct, modify, and operate: a local point for electronics, tools, lab-made products, and the people who use them. One working reference exists today. A worldwide network is the direction, not a claim that it is already open.

Explore the journey → See the network →

The worldwide idea

Build locally. Vend locally. Improve openly. Connect globally.

Seeed Studio wants to help create an open, locally adaptable distribution system that every Fab Lab can improve and every nearby maker community can use. This is a Seeed Studio-led collaboration with Fab Labs. It is not an official program of the Fab Foundation, and a lab listed on FabLabs.io has not joined by default.

  1. 01

    Seeed Studio

    Publishes the reference design and proposes program support around XIAO supply, technical resources, and visibility for participating labs.

  2. 02

    Fab Labs

    Build and operate their own machines. Each lab can change the mechanism, the enclosure, and the products to fit its workshop.

  3. 03

    Local communities

    Makers and students find a nearby place to see the lab, pick up a board, or buy something the lab itself has made.

  4. 04

    Shared improvements

    Reusable machine changes go back to the open project. A product a lab sells does not have to be open source.

  5. 05

    Worldwide network

    Labs that choose to publish a machine can be found by city, with a clear difference between a directory listing and a verified installation.

Program goals · not a confirmed offer

Seeed Studio intends to support this ecosystem with XIAO product supply, the machine reference, open-source collaboration, publicity for participating labs, and future help with replicable designs. Eligibility, pricing, inventory commitments, free machines, subsidies, and guaranteed marketing are not defined here and should not be assumed.

One machine, many possibilities

A shared starting point. A local catalog.

These are ways a lab might use the machine. Only the reference build is operating today. The other two are possibilities, labeled as such.

Program goal · not stocked here

Default starting point: XIAO

XIAO is the compact board family proposed as the default product category, so a visitor in one lab and a visitor in another can find a common starting point. The current reference machine does not use XIAO as its controller.

Possibility · not a current catalog

Local products

A lab can sell electronics, accessories, educational kits, and suitable objects it fabricates itself. Selling a local product does not require that product to be open source. No public price list or live inventory is published yet.

Reference today · other mechanisms are future work

Open modifications

The published files already include an enclosure, a four-column dispenser, and the Wio Terminal interface. Different dispensing mechanisms, compartments, payment interfaces, and software adaptations are open design problems, not features of the current build.

How the open model works

Six steps, then the next lab starts further along.

Machine contributions, stocked products, and program participation stay separate. Improving the mechanism is an open-source act. Choosing what to sell is a local decision. Joining a future Seeed support program will have its own terms, which are not written yet.

  1. 1

    Build

    Reproduce the reference machine from the published parts, CAD, firmware, and backend.

  2. 2

    Customize

    Change what the lab actually needs: product size, enclosure, interface, or local catalog.

  3. 3

    Operate

    Run it in the community. Refill it. Keep the dashboard and the columns in agreement.

  4. 4

    Document

    Write down the modification another lab could reuse, including what it fits and what it does not.

  5. 5

    Publish

    Send the CAD, notes, and test evidence back as a versioned replacement. Version Zero stays intact.

  6. 6

    Pass it on

    The next lab builds from the reference plus the improvements that proved useful.

Why Fab Labs matter

The useful part is the lab, not the cabinet.

A machine in a Fab Lab can make electronic parts easier to reach, give the lab a place to show what it makes, and give people a reason to walk in. These are the local reasons for the project. They are not measured results.

  • Parts within reach

    Makers and students can pick up a board or a small component without waiting on a distant order for every experiment.

  • A local XIAO point

    If the proposed supply program is confirmed, XIAO becomes something a person can find at a lab nearby. That supply is not operating yet.

  • A shelf for local work

    The same machine can carry kits and objects the lab develops, next to the shared default products.

  • A visible workshop

    The machine is also a sign for the lab itself: a place to discover, learn, build, and meet other makers.

The first machine is only the beginning

The first machine is only the beginning.

Version Zero shows that a lab can authenticate a card, release a product, and record the result. The next work is making that build easier to repeat, and only then inviting labs onto a public map.
