The Journey

From one open machine to a global standard.

Follow the reference build, the improvements that still need people, and the work required before vending machines can be reproduced across Fab Labs. Completed items link to evidence. Planned items are not started.

Implementation

Nine systems, each with a status.

Done means the reference repository already contains it. In progress means the public submission path exists and the network does not. Needs contributors is an open problem. Planned is not built.

Product evolution

Version Zero, kept intact.

The interactive model is the exploded view. This list is the same parts, with source CAD. A replacement is appended. It does not erase the previous file. The product-specific dispenser is an alternative, not the next version of the common dispenser.

Contributions

Problems with a place to start.

Each card opens a GitHub issue form. A person still has to do the work. The form asks for the problem, the files involved, and what “done” means. A design replacement also asks for part id, CAD, version, compatibility, test evidence, attribution, and license.
