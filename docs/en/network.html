The Network

Find a Lab. Discover What It Makes.

Explore Fab Labs worldwide, discover participating vending machines, and find locally available XIAO boards and maker products when a lab has actually published them. The map starts from the FabLabs.io directory. A dot there is not a vending machine, and it is not an endorsement by the Fab Foundation.

Lab list

    What visitors can find

    A listing is not a stock count.

    For a reviewed lab, products can appear in the categories below. “Listed product” means the lab named it. “Availability recently confirmed” needs a date. This site does not invent live inventory or prices.

    Seeed Studio XIAO

    The proposed default category. None is confirmed in stock on this site.

    Electronics and components

    Boards, sensors, and parts a lab chooses to carry.

    Locally fabricated items

    Objects the lab makes. They do not have to be open source.

    Educational kits

    Sets prepared for a class or an open night.

    Tools and accessories

    Small tools that belong with the electronics.

    Other supported products

    Anything else a reviewed machine is set up to release.

    Installations

    New machines. New makers. New places.

    Only submitted and approved installations appear here.

    Community updates

    A public stream with a review state.

    Installations, upgrades, new products, availability changes, open-source modifications, and operational notes. Each public item needs a source, a timestamp, and an approved review. A proposal is not a listing.

    Register or update your lab

    GitHub issues, reviewed before publication.

    GitHub Pages cannot save a form by itself. These links open issue forms in the repository. A maintainer reviews the issue, then edits the JSON. A later backend can replace this queue without changing the page’s data files.

    Register interest

    Tell us the lab wants to follow the project. This does not install a machine.

     Submit a confirmed installation

    Machine version, photograph, and a source a reviewer can check.

     Add or update a product listing

    Name and category. A listing is not a claim that it is in stock.

     Update product availability

    A date is required before anything is shown as recently confirmed.

     Announce a machine upgrade

    What changed, and which version is now installed.

     Submit an open-source improvement

    Part id, CAD, version, compatibility, test evidence, attribution, and license.

     Correct an existing listing

    Point at the record that is wrong and the evidence for the correction.

    How the world map is filled

    A daily snapshot, not a live login from the browser.

    The legacy public endpoint at api.fablabs.io has been removed. The current developer guide requires a person to register an application and complete OAuth once. This page only reads directory-labs.json. A GitHub Action can refresh that file after a token is stored as a secret. The steps, including what a person must do and what the Action can do, are in FABLABS_DIRECTORY.md.
