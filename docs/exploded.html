02 / VERSIONED PARTS BOARD

The machine, as replaceable units.

Every card points back to the current file in the repository. When a replacement is added, the same card gains a revision history instead of disappearing.

03 / ADD ONE REPLACEMENT

One new part.
One new record.

You do not edit the V0 baseline. Add the new CAD file to the repository, then append one object to replacements.js. The page automatically makes the last revision current and keeps the previous model available for comparison.

{
  partId: "dispenser",
  version: "V0.1",
  title: "Wide product dispenser",
  source: "replacements/v0.1/wide-dispenser.stl",
  format: "stl",
  date: "2026-10-20",
  note: "What changed and why."
}
04 / 3D DISPLAY STANDARD

Make the model feel like a product,
not a CAD viewport.

The page should preserve engineering truth while presenting the machine with one consistent visual language. These rules apply to V0 and every replacement that follows.

01

Camera

Open on a three-quarter, slightly elevated view. Keep the machine readable at first glance. No permanent auto-spin; motion only follows user intent.

02

Material

Use matte, low-metalness CAD materials. System colors identify groups; color is not decoration. Avoid photoreal textures unless the real surface matters.

03

Focus

The selected/current part becomes lime. Non-selected geometry recedes. When an internal part is selected, the enclosure may ghost rather than disappear.

04

Explosion

Move parts along stable system directions and preserve spatial relationships. Default to a readable editorial explosion, while 0% always returns to the compact system.

05

Labels

Show stable part ID, human name, group, quantity and revision. Keep labels outside the geometry when possible and never cover the object with paragraph text.

06

Motion

Use short ease-out transitions for focus, filtering and replacement changes. Respect reduced-motion settings and never require animation to understand the state.

05 / MODEL PIPELINE

Manufacturing files stay exact.
Web files stay fast.

Do not make the browser parse the manufacturing master forever. Keep STEP/STL as source-of-truth, then publish a web derivative for each released revision.

01

Source CAD

Keep the original STEP/STL in the repository. Never replace V0 in place.

.step / .stl
02

Web derivative

Generate one GLB per part/revision. Use glTF coordinates (+Y up, +Z forward) and stable node names based on part IDs.

.glb
03

Optimize

Remove duplicate data, quantize and compress geometry. Add KTX2 only when future models genuinely need textures.

meshopt / KTX2
04

Publish

Ship source CAD, web GLB, thumbnail, revision note and manifest entry together as one release unit.

source + web + metadata
