01 / NORTH STAR

One open vending machine
in every Fab Lab.

A lab should not need a procurement cycle for every small board, sensor, cable, or locally useful part. The machine becomes lightweight infrastructure: visible, nearby, refillable, and owned by the lab operating it.

The shared layer stays open. The local layer stays flexible. XIAO gives every deployment a common starting point without turning every lab into the same store.

03 / THE SYSTEM

A machine is only the visible layer.

The reusable product is the full system around it: an editable physical machine, local control software, a default catalog, a refill practice, and an open path for each lab to adapt the deployment.

01Open machine

Printable and editable hardware, designed to be reproduced and changed.

02Local operations

Dashboard, inventory, device configuration, and dispense logic that a lab can run.

03XIAO by default

A common starting inventory that makes the network legible without limiting what a lab can add.

04Local catalog

Sensors, kits, adapters, or locally made parts can be added around the needs of each community.

05Shared learning

Useful remixes, fixes, deployment notes, and mechanisms can return to the open project.

04 / OPEN PARTICIPATION MODEL

Standardize the base.
Localize the rest.

The program should create a shared starting point without creating a centrally controlled catalog. These are the proposed principles for the pilot phase; formal program terms will be published before applications open.

A

Start with XIAO

Keep a useful selection of XIAO boards available as the common baseline across participating labs.

B

Vend what matters locally

Add parts that shorten the path from idea to prototype in your own lab, city, school, or community.

C

Publish reusable improvements

When you improve the machine, deployment process, or dispensing mechanism, make the reusable part visible to others.

D

Operate it as local infrastructure

The lab owns the daily reality: placement, refill, maintenance, local assortment, and community fit.

BACKED BY SEEED STUDIO

Reference hardware. XIAO ecosystem. Program support.

The pilot support package, eligibility, supply terms, and application process will be published when the program opens. Version 0 stays focused on making the reference system inspectable and reproducible first.
