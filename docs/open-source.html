The public viewer is intentionally built from open web and CAD tooling. Source CAD remains in the repository; browser derivatives and runtime libraries should stay traceable to their upstream projects and licenses.

Three.js ↗

Primary WebGL renderer for the custom exploded scene, orbit controls, STL display, selection and revision interaction.

MIT

occt-import-js ↗

Open CASCADE/WebAssembly import layer used to triangulate STEP files in the browser for the V0 source-model path.

LGPL-2.1

Online 3D Viewer ↗

Useful reference and conversion tool: it supports many CAD/mesh formats including STEP and STL, and can export glTF.

MIT

glTF Transform ↗

Recommended build-stage tool for cleaning, validating and optimizing web GLB derivatives.

MIT

meshoptimizer / gltfpack ↗

Recommended mesh optimization and compression layer when the number of parts and revisions grows.

MIT

<model-viewer> ↗

Optional lightweight viewer for a single replacement part, mobile-friendly preview, or future AR entry point.

Apache-2.0

Blender ↗

Optional authoring/cleanup tool for staging, normals, materials and GLB export when a manual asset pass is useful.

GPL
