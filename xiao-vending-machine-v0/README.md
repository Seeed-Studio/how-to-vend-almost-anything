# Version 0 — frozen reference

This tree is the permanent reference machine. It already dispenses.

Pull requests leave these files in place. An alternative or a successor is proposed, reviewed, and tested, then published as a new manifest under [`releases/machine/`](../releases/machine/). Version 0 stays here as the baseline.

- Hardware and assembly: [`xiao-vending-machine-assemble-steps/`](xiao-vending-machine-assemble-steps/README.md)
- Software and firmware: [`xiao-vending-machine-full-code-system/`](xiao-vending-machine-full-code-system/)

The official record of this configuration is [`releases/reference.yaml`](../releases/reference.yaml) and [`releases/machine/v0.yaml`](../releases/machine/v0.yaml).
